# Task 10 — Name normalization, installed check and installed grouping

Target: claude

## Goal
Implement the normalizer of feature `plugin-detection` and the two decisions
built directly on it: whether a project reference is installed, and how the
installed plugins group into one plugin across formats. The catalogue index
and the catalogue editor both reuse these functions.

## Acceptance criteria
- `norm(s)` lower-cases and keeps only letters, digits and `.`, so
  `AmpliTube_5.vst3` equals `AmpliTube 5.vst3`.
- `split_name(display)` returns format (`VST`/`VSTi` → vst, `VST3`/`VST3i`
  → vst3, `AU`/`AUi` → au, `CLAP`/`CLAPi` → clap, `LV2`/`LV2i` → lv2,
  `DX`/`DXi` → dx, `JS` → js), base name with trailing `(N out)` / `(Nch)`
  removed repeatedly, and bare name without the last parenthesis.
- `ident_key(ident)` drops everything from `<`; for an identifier ending in
  a plugin file extension keeps only the file name (full paths included);
  then `norm`; AU ids stay whole.
- `missing(refs, installed)` keeps the references whose identifier key
  matches no installed plugin's and whose `format:norm(base name)` matches
  none either.
- `group_installed(installed)` groups installed plugins by `norm(base
  name)`, so the VST2, VST3, AU and CLAP of one plugin form one group.
- Pure Lua, no `reaper.*` calls.
