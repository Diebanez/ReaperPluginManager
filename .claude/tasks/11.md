# Task 11 — Catalogue association and classification

Target: claude

## Goal
Implement the classifier of feature `plugin-detection`: associate each
missing reference with its catalogue entry and sort it into the summary
groups — installable, no installer for this platform, unknown, replace by
hand — for the current platform.

## Acceptance criteria
- A reference or installed plugin looks up, in order, its identifier key,
  `norm(base name)`, `norm(bare name)` in the catalogue index; an entry is
  "present" when any installed plugin associates with it.
- `classify(missing, installed, index, platform)` applies SPEC.md §4.6:
  entry present → replace by hand; installer for this platform →
  installable (grouped per entry, instances summed) and also replace by hand
  when the format cannot load here; entry without installer → no installer;
  no entry and unloadable format → replace by hand; no entry → unknown.
- Loadable formats: Windows vst, vst3, clap, lv2, dx; macOS vst, vst3, au,
  clap, lv2.
- With no catalogue, nothing is installable and the rest classifies
  normally.
- Pure Lua, no `reaper.*` calls.
