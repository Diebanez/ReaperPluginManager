# Task 14 — Action registration, startup hook and connection test

Target: claude

## Goal
Implement the second half of feature `setup-action`: after saving, register
the tool's four actions, install the startup hook so projects are checked
from every REAPER start, start the watcher at once, and test the connection.

## Acceptance criteria
- Registers Watcher, Check project, Catalogue management and Setup with
  `reaper.AddRemoveReaScript(true, 0, path, last)`; re-running does not
  duplicate them.
- Creates `Scripts/` under the resource path if missing and writes into
  `__startup.lua` the block between `-- >>> ReaperPluginManager` and
  `-- <<< ReaperPluginManager` that runs the watcher inside `pcall` and
  reports a failure to the console; an existing block is replaced in place,
  the rest of the file untouched. A failed write is shown to the user.
- Starts the watcher immediately with `reaper.Main_OnCommand` using the
  command id the registration returned.
- Fetches the catalogue and reports "Connection succeeded: the catalogue
  lists N plugins" or the failure reason; a failed test leaves the saved
  settings in place.
- A failure in one step is reported and the remaining steps still run where
  they can.
