# Task 16 — Project check assembly

Target: claude

## Goal
Implement the check core of feature `project-watcher`: given a project,
gather the installed plugins, read the saved project file, fetch the
catalogue and classify — one result value the summary window and the check
action both render.

## Acceptance criteria
- Enumerates installed plugins with `reaper.EnumInstalledFX(i)` until it
  returns false.
- Reads the project file from disk; an unsaved project (empty path) or a
  missing file returns a distinct "not saved" / "file missing" result.
- Fetches the catalogue (`plugin-catalogue`), runs `scan_project`,
  `missing` and `classify` (`plugin-detection`) for the current platform,
  and includes the catalogue `source` and fallback `reason`.
- Includes the activation-pending entries among the project's installed
  plugins through `licence-activation.pending_for`, tolerating its absence
  until that feature lands (empty list).
- Returns the total plugin count, so "All N plugins are installed" can be
  reported.

## Decisions
- `pending_for` is optional at runtime so the check works before
  `licence-activation` is implemented; task 17 is where the pending group is
  shown.
