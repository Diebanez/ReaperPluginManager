# Task 17 — Summary window and Check project action

Target: claude

## Goal
Implement the user-facing window of feature `project-watcher`: one
scrollable `gfx` window per check listing every finding without truncation,
with the install hand-off, plus the "Check project" action that always shows
a result.

## Acceptance criteria
- One window per check, scrollable, grouped: to install (`Name (Vendor) —
  note`), no installer for this platform, not in the catalogue (`Name
  (Vendor) [FORMAT] ×instances`, only when `notify_unknown` is on),
  instances to replace by hand, activation pending (each with an Activate
  button calling `licence-activation.activate`).
- A banner line when the cached catalogue was used, with the reason.
- Buttons "Install N plugins" (only with something installable) and
  "Close"; Install calls `plugin-installation.start` with the installable
  entries and closes the window.
- The Check project action runs the check on the current project and shows
  the window, "All N plugins are installed", or "Save the project first".
- Nothing is truncated: no "… and N more" lines.
