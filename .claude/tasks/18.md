# Task 18 — Background watcher loop

Target: claude

## Goal
Implement the watcher of feature `project-watcher`: a single background
`defer` loop that checks every saved project each time it is opened,
survives errors, defers checks while an install runs, and reopens the
project after a restart.

## Acceptance criteria
- Exits at once when `check.auto` is off.
- Writes a heartbeat to the non-persistent ExtState
  `ReaperPluginManager/watcher_heartbeat` each cycle; an instance finding a
  heartbeat younger than 3 s at start exits.
- Every second lists open project tabs as (project, path) pairs; a pair
  present now and not in the previous poll, with a non-empty path, is an
  open event, checked on the following poll. Tab switching triggers
  nothing; closing and reopening a project does.
- Each check runs in `pcall`; an error goes to the REAPER console and the
  loop continues.
- While `plugin-installation.is_running()`, open events queue and are
  checked after the run ends.
- At start, calls `plugin-installation.reopen_after_restart()` once.
- A window appears only when the check finds something to list.
