# Task 20 — Job file writer, URL encoding and status file reader

Target: claude

## Goal
Implement the pure half of feature `plugin-installation`: the two files that
are the whole contract between the Lua side and the install helpers — the
job file it writes and the status file it reads.

## Acceptance criteria
- The job writer emits one UTF-8 line per entry, tab-separated `id name type
  url sha256 args dest`, with tabs and newlines inside fields replaced by a
  space.
- `url` = server URL + installer `file` with `\` → `/`, leading `/` removed,
  every character outside `[A-Za-z0-9-._~/]` percent-encoded (space →
  `%20`).
- The status reader parses `START <n>`, `ITEM <id> download|verify|install`,
  `OK <id>`, `FAIL <id> <message>`, `DONE <ok> <failed>`; counts only lines
  ending in `\n` (`\r\n` tolerated), ignores a leading BOM, accepts `START`
  twice, and returns per-entry state plus whether `DONE` was seen.
- Pure Lua in `rpm_core.lua`, no `reaper.*` calls.
