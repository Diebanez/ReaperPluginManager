# Task 21 — Install run: launch, progress window, summary and reopen

Target: claude

## Goal
Implement the REAPER side of feature `plugin-installation`: start one
install run at a time, launch the platform helper without blocking REAPER,
follow it in a progress window, report the outcome, hand over to licence
activation, and reopen the project after REAPER restarts.

## Acceptance criteria
- `start(entries)` refuses while a run is in progress; otherwise writes the
  job, deletes the old status file, prepares the credentials file through
  `server-access`, and launches: Windows `reaper.ExecProcess(cmd, -2)` with
  `powershell.exe -NoProfile -ExecutionPolicy Bypass -WindowStyle Hidden
  -File …`; macOS `/bin/bash … >/dev/null 2>&1 &`. Paths carry no trailing
  backslash; arguments without a value are omitted.
- A `gfx` progress window shows each plugin as queued / downloading… /
  verifying… / installing… / installed (green) / failed (red), refreshed
  each `defer` cycle; closing it leaves the run going.
- No status line 30 s after launch → reported as "the installer helper did
  not start".
- At `DONE`: a summary of installed and failed plugins with messages; the
  installed entries go to `licence-activation.after_install`; when anything
  was installed, the restart message and the persistent ExtState
  `ReaperPluginManager/reopen` = project path.
- `reopen_after_restart()` waits 2 s after start, deletes the record, and
  opens the recorded project with `reaper.Main_openProject` if it is not
  the active one and still exists.
- `is_running()` reports the run state.
