# Task 23 — Windows helper core: elevation, download, verify, exe/msi

Target: claude

## Goal
Implement the core of feature `install-helper-windows`: the Windows
PowerShell 5.1 helper that reads the job, elevates once, downloads and
verifies each installer, installs `exe` and `msi` entries, and reports every
step to the status file per the helper contract.

## Acceptance criteria
- Parameters `-JobFile -StatusFile -WorkDir -NetrcFile -Tls -Insecure
  -Vst3Dir -Vst2Dir -ClapDir -NoElevate`, with the documented defaults.
- Writes `START <n>` at once; when not administrator and without
  `-NoElevate`, relaunches with `Start-Process -Verb RunAs` forwarding every
  parameter and exits; a refused prompt → `FAIL <id> administrator
  permission denied` for every plugin and `DONE 0 n`.
- Per entry: `ITEM download` (curl into `work/<id>/`, file name = decoded
  last URL segment, error preference relaxed around the call and
  `$LASTEXITCODE` read), `ITEM verify` when a checksum is given (.NET
  `SHA256`, case-insensitive), `ITEM install`, then `OK` or `FAIL
  <message>`; a failure stops only that plugin; `work/<id>` deleted on
  success, kept on failure.
- `exe`: `Start-Process -Wait -PassThru` with `args`; `msi`: `msiexec /i
  "<file>" /qn /norestart <args>`; success on exit code 0 or 3010. Other
  types (except `zip`, task 24) → "installer type not supported on
  Windows".
- Status lines appended with `[IO.File]::AppendAllText` (UTF-8 without
  BOM); ends with `DONE <ok> <failed>` and deletes the credentials file.
- The script is ASCII-only and avoids `Get-FileHash` / `Expand-Archive`.
