# Task 24 — Windows helper zip routing

Target: claude

## Goal
Add `zip` entries to feature `install-helper-windows`: unpack the archive
and copy its outermost plugin items to the right plugin folders, preferring
64-bit copies over 32-bit ones.

## Acceptance criteria
- Unpacks with `[IO.Compression.ZipFile]::ExtractToDirectory` after
  `Add-Type -AssemblyName System.IO.Compression.FileSystem`.
- Copies only outermost plugin items, without descending into an item
  already found: `.vst3` (file or folder) → Vst3Dir, `.clap` → ClapDir,
  `.dll` → Vst2Dir; an entry's `dest` (`vst3`, `vst2`, `clap` or an absolute
  path) overrides routing.
- An existing destination item of the same name is deleted before copying.
- When the same name appears more than once, the copy whose relative path
  marks it 32-bit (`x86`, `32bit`, `32-bit`, `win32`, `32`) is dropped,
  provided one copy is not so marked.
- No plugin found → `FAIL <id> no plugin (.vst3, .clap, .dll) in the
  archive`.
