# Task 26 — macOS helper core: download, verify, zip routing, quarantine

Target: claude

## Goal
Implement the core of feature `install-helper-macos`: the bash 3.2 helper
that reads the job, downloads and verifies each installer, installs `zip`
entries into the user's plugin folders, clears quarantine, and reports every
step to the status file per the helper contract.

## Acceptance criteria
- Options `--job --status --workdir --netrc --tls --insecure
  --plugins-root` (default `~/Library/Audio/Plug-Ins`).
- Job lines read with tabs converted to `\037` and `IFS=$'\037'`, so empty
  fields survive; no associative arrays, `mapfile` or `${var,,}`.
- Writes `START <n>`; per entry `ITEM download` (curl into `work/<id>/`,
  file name = decoded last URL segment), `ITEM verify` with `shasum -a 256`
  when a checksum is given, `ITEM install`, then `OK` or `FAIL <message>`;
  a failure stops only that plugin; `work/<id>` deleted on success, kept on
  failure.
- `zip`: `ditto -x -k`, then copy outermost bundles: `.vst3` → `VST3/`,
  `.component` → `Components/`, `.vst` → `VST/`, `.clap` → `CLAP/`; `dest`
  overrides; `__MACOSX` ignored; existing same-name item deleted first;
  `xattr -dr com.apple.quarantine` on each copied item.
- `unzip` and `cp -R` are used when `ditto` / `xattr` are missing (Git Bash
  development runs).
- Unsupported types (except `dmg`/`pkg`, task 27) → "installer type not
  supported on macOS"; ends with `DONE <ok> <failed>` and deletes the
  credentials file.
