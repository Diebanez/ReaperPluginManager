# Task 27 — macOS helper dmg and single-password pkg phase

Target: claude

## Goal
Add disk images and packages to feature `install-helper-macos`: mount a
`dmg` and either queue its package or copy its bundles, and install every
queued `pkg` in one administrator-privileged run with a single password
prompt.

## Acceptance criteria
- `dmg`: `yes | hdiutil attach -nobrowse -readonly -noautoopen -mountpoint
  …`; a `.pkg`/`.mpkg` within two levels is copied into the work folder and
  queued; otherwise bundles are routed as for `zip`; then `hdiutil detach`,
  retried with `-force` when needed.
- `pkg` entries are queued.
- After all other entries, one generated script runs `/usr/sbin/installer
  -pkg … -target /` per queued package and writes its `OK`/`FAIL` line; it
  runs once via `osascript -e 'do shell script "…" with administrator
  privileges'`.
- A cancelled password prompt → `FAIL <id> administrator password not
  entered` for every package without an outcome.
- `DONE` is written only after the package phase.
