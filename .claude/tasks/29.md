# Task 29 — Activation field, pending record and pending query

Target: claude

## Goal
Implement the data half of feature `licence-activation`: read the catalogue
entry's `activation` field, keep the local record of plugins still pending
activation, and answer which of a project's installed plugins are pending.

## Acceptance criteria
- Reads `activation.method` (`none` | `vendor-app` | `serial` | `sign-in`,
  absent = `none`), `activation.app.windows` / `.macos` (display name and
  expected location), `activation.url` and `activation.instructions`;
  unknown methods are treated as `none` with a console warning.
- The pending record lives in `activation.ini` in the local data folder:
  one key per pending entry id, valued with the date it was recorded;
  functions to mark pending and to clear.
- `pending_for(installed_refs, catalogue)` returns the pending entries that
  any of the given installed plugins associates with.
- Only entries passed through the walk-through are ever recorded; plugins
  the tool did not install are never tracked.
