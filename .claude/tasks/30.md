# Task 30 — Activation walk-through window and openers

Target: claude

## Goal
Implement the walk-through of feature `licence-activation`: after an install
run, a `gfx` window walks the member through each needed activation —
grouped per vendor app — opening the vendor's app or page, and records Done
or Later.

## Acceptance criteria
- `after_install(entries)` records every entry with a method other than
  `none` as pending, then opens the walk-through; it returns when the window
  closes, so installation can show its restart message. With nothing to
  activate it returns at once.
- Steps: one per vendor app (entries sharing an app listed together), one
  per entry otherwise; each shows the plugin name(s) and the instructions,
  with Activate, Done and Later buttons.
- Activate: `vendor-app` opens the app when found at its recorded location,
  else its download page; `serial` and `sign-in` open the vendor page; a
  missing `url` leaves only the instructions. Windows uses `start ""
  "<target>"` through `ExecProcess`; macOS `open -a "<app>"` / `open
  "<url>"`.
- Done clears the step's entries from the pending record; Later and closing
  the window leave them pending.
- `activate(entries)` reopens the walk-through for specific entries (used by
  the summary window).
