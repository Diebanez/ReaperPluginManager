# Task 31 — Saved serials and clipboard copy

Target: claude

## Goal
Implement the fast-reactivation part of feature `licence-activation`: offer
to save a member's own serial in the OS secret store after activating a
`serial` plugin, and copy a saved serial to the clipboard on Activate —
without the serial ever reaching a command line, a plain file or the server.

## Acceptance criteria
- After Done on a `serial` entry with no saved serial, a masked REAPER
  dialog offers to save it; cancelling saves nothing.
- Serials are stored with the secret-store helpers of task 2 under
  per-entry keys, separate from the server credential.
- Activate on an entry with a saved serial copies it to the clipboard by a
  process that reads it from the secret store directly (PowerShell
  `Set-Clipboard` on Windows, `security … -w | pbcopy` on macOS).
- A secret-store failure skips the copy and says so, without changing the
  pending record.
