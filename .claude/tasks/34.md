# Task 34 — Add entries: from installed, by hand, from a draft file

Target: claude

## Goal
Implement the three ways feature `catalogue-editor` adds an entry: picking a
plugin from REAPER's installed list (capturing how each format names itself),
typing it by hand, or importing a draft entry file the catalogue assistant
wrote.

## Acceptance criteria
- Add from installed lists `group_installed` groups, hiding Cockos plugins
  (base name ending in `(Cockos)`), JSFX and groups the draft already
  covers; picking one creates an entry with `id` = unique slug of the bare
  name, `name`, `vendor` = last parenthesis, `match` = base name plus every
  distinct identifier (file name only for file plugins).
- Add by hand takes name, vendor and match strings.
- Import draft lists the files in the `drafts/` folder of the local data
  folder, validates the chosen one against the catalogue schema, adds it or
  — after confirmation — merges it into the entry with the same `id`, and
  removes the imported file.
- An imported entry's installers keep their existing server paths and are
  marked as already on the server.
