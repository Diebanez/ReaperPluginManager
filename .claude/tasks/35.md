# Task 35 — Entry form, checksums and removal

Target: claude

## Goal
Implement the entry form of feature `catalogue-editor`: edit every field of
an entry — note, installers per platform or one shared package, install
options, activation — with checksums computed automatically, and remove
entries from the draft.

## Acceptance criteria
- The form edits note; per platform or once as a shared package: installer,
  type, silent-install arguments, destination; activation method, app per
  platform (name and location), URL and instructions.
- Attaching a local file computes its SHA-256 with OS tools (`certutil` or
  PowerShell on Windows, `shasum -a 256` on macOS) and assigns its server
  path: `<id>/windows/<file>`, `<id>/macos/<file>`, or `<id>/<file>` for a
  shared package named under both installer keys.
- An installer already on the server keeps its path and is never uploaded.
- A failed checksum leaves it empty and says so; a vanished local file is
  flagged on its entry; an invalid entry blocks Publish.
- Remove deletes an entry from the draft.
