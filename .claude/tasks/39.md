# Task 39 — Catalogue assistant Claude Code skill

Target: claude

## Goal
Implement feature `catalogue-assistant`: a Claude Code skill in this
repository that researches one plugin from official vendor sources, inspects
its installers already on the group's server, and writes a draft catalogue
entry for the editor to import, with a review report.

## Acceptance criteria
- `SKILL.md` takes the plugin name and vendor plus the server paths of its
  installers, and states the boundaries: official vendor sources only; no
  serials, accounts, cracks, keygens or vendor-site downloads.
- A fetch script downloads each named installer from the group's server into
  a temporary folder using the tool's settings and the secret-store
  credentials, materializing the credentials file itself so the password
  never enters the conversation; the folder is deleted afterwards.
- The skill identifies each installer's type and generator (Inno Setup,
  NSIS, InstallShield, WiX/MSI, pkg, dmg, zip), proposes matching silent
  switches, and computes its SHA-256.
- It writes `drafts/<id>.json` in the tool's local data folder: one entry
  valid against catalogue format v1, installers at their existing server
  paths, `activation` filled from research.
- The report lists each field with its source and confidence; silent
  switches and unconfirmed match strings are always marked "test by hand
  before publishing"; unknown fields are left empty and listed.
- Nothing under `.claude/skills/catalogue-assistant/` is part of the release
  zip.
