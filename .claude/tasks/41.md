# Task 41 — License the project under GPL-3.0

Target: claude

## Goal
Give the repository an open-source licence before it is made public and
released through ReaPack: the full GNU General Public License v3.0 in a
`LICENSE` file at the root, and a statement of it in the member-facing
`README.md`.

## Acceptance criteria
- `LICENSE` at the repository root holds the canonical, unmodified GPL-3.0
  text, fetched rather than retyped (`gh api licenses/gpl-3.0 --jq .body`),
  so GitHub detects the repository's licence as GPL-3.0.
- `README.md` ends with a short *Licence* section stating that
  ReaperPluginManager is licensed under the GNU General Public License
  v3.0 and pointing to `LICENSE`.
- No source file gains a per-file licence header.

## Decisions
- **GPL-3.0 (user decision, 2026-10-23).** The licence is the user's choice,
  made with the decision to release through ReaPack.
- **No per-file licence headers.** The root `LICENSE` and the README
  statement are what the user asked for; the ReaPack package header (task
  42) carries no licence tag, because reapack-index's packaging
  documentation defines none.
