# Task 44 — Script installer type and the unmanaged-installer check

Target: claude

## Goal
Implement the `script` installer type and the unmanaged-installer flag of
feature `plugin-catalogue`: the catalogue accepts `type` `script` on both
platforms, a zip carrying an install script for a plugin no silent installer
or plain plugin files can install (Polarity Audio's The Cue), and exposes
`catalogue.unmanaged(entry, platform)`, from which `project-watcher` and
`catalogue-editor` read whether an entry's installer on a platform runs a
script from the server (with administrator rights on Windows, with the
member's own rights on macOS).

## Acceptance criteria
- `script` is a known installer type on Windows and on macOS beside the
  existing ones, and a missing `type` is never derived as `script`: the
  extension derivation still yields only `exe`, `msi`, `zip` on Windows and
  `pkg`, `dmg`, `zip` on macOS, so a `.zip` with no `type` stays a `zip`.
- `catalogue.validate` keeps an entry whose installer is `script` usable,
  with its `file` and `sha256` as for any installer; `args` and `dest` on a
  `script` installer are carried through untouched and not rejected.
- `catalogue.unmanaged(entry, platform)` returns true exactly when the
  entry's installer for `platform` (`windows` or `macos`) is present and of
  type `script`; false for any other type, an absent installer, or a
  malformed entry. It never raises and makes no `reaper.*` call.
- `server/manifest.example.json` gains a valid version-1 entry with a
  `script` installer on each platform, modelled on The Cue (a VST3 plus its
  data folder), and the file still validates with no warnings.

## Decisions
- The example entry follows the feature document's own case (The Cue, a
  per-platform zip each) so the server guide's worked example, written by
  the change's documentation, can point at it.
- No rule is added for `args` or `dest` on a `script` installer: the
  document says they do not apply, so the helpers ignore them rather than
  the catalogue skipping the entry.
