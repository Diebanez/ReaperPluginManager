# Task 45 — Update documentation for feature `plugin-catalogue`

Target: claude

## Goal
Feature `plugin-catalogue` gains the `script` installer type and the
unmanaged-installer flag (task 44), and the maintainer's description of the
catalogue format is now out of date: bring `server/README.md` § The
catalogue format in line with the shipped behavior.

## Acceptance criteria
- § The catalogue format lists `script` among the `type` values of both
  platforms, and states that it is never taken from the file extension, so
  a script installer always names its `type`.
- It states what a `script` installer's `file` is: a zip holding, at its
  root, `install.ps1` (Windows) or `install.sh` (macOS) plus the files the
  script installs; that `sha256` covers the zip; that `args` and `dest` do
  not apply; and that a package shared by both platforms may be `script`
  when the zip holds both scripts.
- It states that an entry with a `script` installer is an unmanaged
  installer on that platform — a script from the group's server that runs
  with administrator rights — and that members are warned before one is
  installed.
- `README.md` is not touched, and the environment variables, exit codes and
  worked example of a script installer are not written here.

## Decisions
- The member and maintainer guides are updated once for the whole script
  change, each passage by one documentation task: this task owns only
  § The catalogue format. The script-installer section of `server/README.md`
  (how to build the zip, the `RPM_*` variables, exit codes, the worked
  example) belongs to feature `catalogue-editor`'s documentation task, the
  helper sections to each helper feature's, and `README.md`'s warning to
  `project-watcher`'s.
