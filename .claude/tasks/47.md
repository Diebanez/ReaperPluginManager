# Task 47 — Update documentation for feature `install-helper-windows`

Target: claude

## Goal
Feature `install-helper-windows` installs `script` entries (task 46), and the
maintainer's description of Windows installers is now out of date: bring
`server/README.md` § Installers on Windows in line with the shipped behavior.

## Acceptance criteria
- § Installers on Windows lists `script` beside `exe`, `msi` and `zip`: the
  zip is unpacked and its `install.ps1` runs with Windows PowerShell 5.1,
  with the run's administrator rights and no extra prompt; a zip with no
  `install.ps1` at its root fails with "no install.ps1 in the archive"; only
  exit code 0 counts as success.
- The sentence naming the types that fail as unsupported on Windows matches
  the four supported types.
- The environment variables, the failure message taken from the script's
  output, and the worked example are not written here.

## Decisions
- This task owns only § Installers on Windows. The script-installer section
  of `server/README.md` (building the zip, the `RPM_*` variables, exit codes,
  the worked example) belongs to feature `catalogue-editor`'s documentation
  task, which writes the whole change's cross-platform passage once.
