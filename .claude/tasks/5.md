# Task 5 — JSON parser and encoder in pure Lua

Target: claude

## Goal
Implement the JSON codec of feature `plugin-catalogue`: REAPER ships no JSON
library, and the catalogue is read by every member and written by the
maintainer's editor, so the tool needs its own parser and a readable encoder.

## Acceptance criteria
- `json.decode(text)` handles objects, arrays, strings with all escapes
  including `\uXXXX` and surrogate pairs (emitted as UTF-8), numbers,
  `true`/`false`/`null`, and a leading UTF-8 BOM; on malformed input it
  returns `nil` plus an error naming the byte position.
- `json.encode(value)` produces indented output; object keys follow the
  fixed order `id, name, vendor, note, match, installers, file, type, args,
  sha256, dest, activation`, then any other keys alphabetically.
- Empty Lua tables encode unambiguously (arrays where the schema expects
  arrays, e.g. `match`), and `null` round-trips through a sentinel.
- Decode → encode → decode round-trips every catalogue value without loss.
- Pure Lua in `rpm_core.lua`, no `reaper.*` calls.
