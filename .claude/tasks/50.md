# Task 50 — Unmanaged-installer mark and install warning

Target: claude

## Goal
Implement the unmanaged-installer safeguard of feature `project-watcher`:
the summary window marks every installable plugin whose installer on this
platform is an install script, and "Install" asks for confirmation in one
prompt naming every such plugin before anything runs, so a member never
starts a script from the server without being told what rights it runs
with.

## Acceptance criteria
- In the summary window's "to install" group, an entry that
  `core.catalogue.unmanaged(entry, <this platform>)` flags carries
  "unmanaged installer" beside its name; other entries are unchanged, and
  nothing is truncated.
- On "Install N plugins", when the installable entries include at least one
  unmanaged installer, one confirmation prompt names every such plugin and
  says, worded for the platform: on Windows, that it uses an unmanaged
  installer, a script from your group's server that runs with administrator
  rights; on macOS, that it uses an unmanaged installer, a script from your
  group's server that runs on this Mac with your user's rights; on both,
  "Continue only if you trust the server's maintainer."
- Confirming passes all installable entries to `install.start` and closes
  the window, as without unmanaged installers; declining starts nothing.
- With no unmanaged installer among the installable entries, "Install"
  behaves exactly as before, with no prompt.
- The automatic check and the Check project action share this behavior,
  since both use the one summary window.
