# Task 51 — Update documentation for feature `project-watcher`

Target: claude

## Goal
Feature `project-watcher` marks unmanaged installers in the summary window
and warns before installing them (task 50), and the member guide is now out
of date: bring `README.md` in line with the shipped behavior, so a member
knows what the mark and the warning mean and what to do with them.

## Acceptance criteria
- `README.md` § The summary window states that a plugin marked "unmanaged
  installer" installs through an install script the group's maintainer put
  on the server, which runs with administrator rights on Windows and with
  the member's own rights on macOS.
- `README.md` § Installing plugins states that, when the run includes such
  a plugin, a prompt naming each one asks for confirmation first; that the
  member should continue only when they trust the server's maintainer; and
  that declining installs nothing.
- It is the only passage of `README.md` this change adds or alters;
  `server/README.md` is not touched.

## Decisions
- This task owns `README.md` for the whole script-installer change: the
  member guide needs only the warning's meaning, while every maintainer-side
  passage lives in `server/README.md` under the other features'
  documentation tasks.
