# Task 55 — Cross-script install running state and start without reopen

Target: claude

## Goal
Extend plugin installation for feature `catalogue-browser`: an install run
becomes visible to every REAPER action through a non-persistent ExtState
heartbeat, so `is_running()` and `start`'s refusal hold across scripts (each
action runs in its own Lua state), and `start` gains an option for a run with
no project to reopen, which the browser uses.

## Acceptance criteria
- While a script's own run is in progress — from `start` until its summary,
  licence activation hand-off and restart message are done — that script
  refreshes the non-persistent ExtState `ReaperPluginManager/install_heartbeat`
  with the current time each defer cycle, and deletes it when the run ends
  (including when the run's window loop fails and the run is dropped).
- `install.is_running()` is true for the script's own run, or when the
  heartbeat is younger than 3 s, as `watcher.is_running` judges its own
  heartbeat.
- `install.start` refuses with "An install is already running." whenever
  `is_running()` is true, so two scripts never share the job and status files
  at once.
- `install.start(entries, opts)` accepts `opts.reopen == false`: such a run
  writes no reopen record, and its restart message reads "Restart REAPER: it
  detects the new plugins at startup. If a plugin does not appear:
  Preferences > Plug-ins > VST > Re-scan." Without the option (the project
  check's calls) the reopen record and the existing message are unchanged.
- The watcher's pause during an install (`poll` checking
  `install.is_running()`) covers runs started by any script, with no change
  to the watcher itself.

## Decisions
- The heartbeat is kept alive for as long as the in-memory run is (through
  the activation walk-through and the restart message), not only while the
  progress loop runs, since catalogue-browser.md states it is refreshed each
  defer cycle of the run and deleted when the run ends; a dedicated small
  defer ticker, or an equivalent, is the implementer's choice.
