# Task 56 — Shared unmanaged confirmation and list primitives

Target: claude

## Goal
Extract from the project check's summary window what the catalogue browser
of feature `catalogue-browser` reuses, so both windows call one copy: the
unmanaged-installer confirmation as `confirm_unmanaged(items, platform,
title)`, and the list primitives — text wrapping, button drawing and
hit-testing, scrolling keys and wheel, scrollbar, catalogue-source banner.

## Acceptance criteria
- `confirm_unmanaged(items, platform, title) → bool` takes the entries to
  install (each carrying `entry`), the platform and the message-box title;
  it returns true at once when none is unmanaged on that platform, otherwise
  shows the one prompt naming every such plugin with the existing platform
  wording, unchanged, and returns whether the member confirmed.
- The summary window's Install calls it with its installable entries, its
  platform and its own title; its behaviour is unchanged.
- The scroll-key and wheel handling, the scrollbar drawing and the
  catalogue-source banner (built from a source and a reason) are functions
  the summary window calls and another window in the module can call; text
  wrapping, button drawing and hit-testing are reused as they stand.
- The summary window looks and behaves exactly as before.
