# Task 57 — Catalogue browser rows and search filter

Target: claude

## Goal
Implement the pure logic of feature `catalogue-browser` in the pure-logic
module: each valid catalogue entry's state on this machine, as one row the
browser window lists and installs from, and the search filter over those
rows.

## Acceptance criteria
- `browse.rows(catalogue, installed, platform) → rows[]` returns one row
  `{ entry, state, installer, unmanaged }` per entry of the validated
  catalogue, sorted by entry name case-insensitively.
- `state` is `installed` when the entry is in
  `present_entries(installed, catalogue.index(catalogue))` (installed wins
  over every other state); otherwise `installable` when
  `catalogue.installer(entry, platform)` returns an installer; otherwise
  `no_installer`.
- `installer` is that platform installer (nil when there is none) and
  `unmanaged` is `catalogue.unmanaged(entry, platform)`, so an installable
  row is directly an item `install.start` accepts.
- `browse.filter(rows, text) → rows[]` keeps the rows whose entry name
  contains `text` as a case-insensitive plain substring (no pattern
  characters interpreted), in order; an empty text keeps every row.
- A nil or empty catalogue yields no rows. Neither function makes a
  `reaper.*` call.
