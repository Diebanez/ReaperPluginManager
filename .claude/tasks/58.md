# Task 58 — Catalogue browser window and Browse action

Target: claude

## Goal
Implement the member-facing part of feature `catalogue-browser`: the action
"Script: RPM_Browse.lua" and the scrollable `gfx` window it opens, listing
every catalogue plugin with its state here, a search field, ticks on
installable rows, and an Install that hands the ticked plugins to plugin
installation with no project to reopen.

## Acceptance criteria
- `RPM_Browse.lua` (`-- @noindex`, beside the other actions) only calls the
  REAPER-side module, as `RPM_CheckProject.lua` does. It runs the guard;
  refuses with "An install is already running. Try again when it has
  finished." when `install.is_running()` is true; otherwise lists installed
  plugins (`check.installed`), fetches the catalogue, builds the rows and
  opens the window. No catalogue at all → a message carrying the fetch
  reason and no window; a catalogue with no plugins → "The catalogue lists
  no plugins."
- The window's heading counts the catalogue's plugins, how many are
  installed and how many installable; the shared catalogue-source banner
  says when the cached catalogue was used and why. Under it the search
  field, then the filtered rows.
- An installable row carries a checkbox toggled by a click anywhere on the
  row; installed and no-installer rows carry none and show "installed" or
  "no installer for Windows" / "no installer for macOS". A row reads
  `Name (Vendor)`, with "unmanaged installer" beside the name of an
  unmanaged entry and the maintainer's note after it, as the summary window
  writes them. Ticks are kept by entry id, so filtering never drops a tick
  on a hidden row.
- Buttons: "Install N plugins", counting every ticked entry, shown only when
  N > 0, and "Close".
- Keyboard: printable characters append to the search text, Backspace
  removes the last character, Escape clears a non-empty search and otherwise
  closes the window; the arrow, page and Home/End keys and the wheel scroll
  the list, through the shared list primitives.
- On Install: when `is_running()` has become true, the refusal message is
  shown and the window stays open. Otherwise `confirm_unmanaged` runs over
  the ticked entries; declining keeps the window and its ticks. Once
  confirmed, the window closes and the ticked rows go to
  `install.start(rows, { reopen = false })`; a refusal from `start` is shown
  as a message.
- An error in a window cycle goes to the REAPER console and closes the
  window, as the summary window does.

## Decisions
- Whether `gfx.getchar` delivers non-ASCII characters, and in which
  encoding, stays the feature document's open question: the task handles
  printable ASCII, which does not depend on it, and leaves non-ASCII typing
  to the check in REAPER on both platforms.
