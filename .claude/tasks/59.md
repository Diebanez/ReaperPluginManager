# Task 59 — Register the Browse action in Setup and the package

Target: claude

## Goal
Ship the action of feature `catalogue-browser`: setup registers
"Script: RPM_Browse.lua" with the other actions and names it in its report,
and the ReaPack package carries it.

## Acceptance criteria
- `setup.register_actions` registers `RPM_Browse.lua` with the other action
  scripts; an already registered path keeps its command id, and a missing
  file is reported like any other.
- The setup report's "Actions registered:" line names
  "Script: RPM_Browse.lua" with the other four.
- `RPM_Setup.lua`'s `@provides` lists `[main] RPM_Browse.lua`, and its
  `@about` says the package adds five actions, naming
  *Script: RPM_Browse.lua* among them.
- `@version`, `@changelog` and `index.xml` are not touched, and no tag is
  made.

## Decisions
- No version bump and no tag: the ReaPack `@version` and the tag belong to
  the release step (catalogue-browser.md § Scope and non-goals).
