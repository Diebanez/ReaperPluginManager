# Task 6 — Catalogue validation and match index

Target: claude

## Goal
Implement the schema half of feature `plugin-catalogue`: validate a decoded
catalogue against format version 1 and build the lookup index that maps every
normalized match string to its entry.

## Acceptance criteria
- `catalogue.validate(value)` rejects the whole catalogue when `version` is
  missing or greater than 1, or `plugins` is not an array.
- Within an accepted catalogue, an entry missing `id`, `name` or `match`, an
  `id` containing spaces, or a repeated `id` is skipped and returned as a
  warning; every other entry stays usable.
- An installer object with an empty `file` is treated as absent; a missing
  `type` is derived from the file extension.
- `activation` is carried through untouched (its content is
  `licence-activation`'s).
- `catalogue.index(catalogue)` maps `norm(m)` for every match string of
  every entry to that entry, using `plugin-detection`'s `norm`.
- `server/manifest.example.json` holds a valid version-1 example with one
  per-platform entry and one shared-package entry (the same `file` under
  both `installers` keys).
