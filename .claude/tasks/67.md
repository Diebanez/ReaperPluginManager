# Task 67 — Update documentation for feature `catalogue-editor`

Target: claude

## Goal
Feature `catalogue-editor`'s Import draft attaches the local installers a
draft entry file names by `source` (task 66), and the server setup guide
still says every installer an imported entry names is already on the
server: bring `server/README.md` in line with the shipped behaviour.

## Acceptance criteria
- § The local draft, **Import draft**: a draft entry file's installer names
  either a server file (`file`), kept at its path and never uploaded, or a
  local file (`source`, an absolute path, with `type`, `args` and `dest`),
  attached on import as **Attach file...** attaches one — checksum computed,
  server path assigned, uploaded on publish; the same `source` under both
  keys is a shared package; a `source` missing at import is flagged on its
  entry.
- § Where installers go on the server: an installer attached from your disk
  or from a draft's `source` takes the `<id>/...` path; one an imported
  draft names by `file` keeps its own path.
- No other section changes, and the guide still does not mention the
  catalogue assistant.
