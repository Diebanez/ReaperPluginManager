# Task 7 — Catalogue fetch with cached fallback

Target: claude

## Goal
Implement the fetch of feature `plugin-catalogue`: download `manifest.json`
from the server root through `server-access`, replace the local cache only
with a valid catalogue, and fall back to the cache — with the reason — when
the server cannot be reached or serves something invalid.

## Acceptance criteria
- `catalogue.fetch()` downloads to a temporary file, decodes and validates
  it; on success the cache is replaced and `source = "server"`.
- Any failure (transfer, JSON, validation) leaves the cache untouched and
  returns the cached catalogue with `source = "cache"` and a one-line
  `reason`; with no usable cache it returns `nil`, `source = "none"` and the
  reason.
- The cache records the server URL it came from; a cache from a different
  URL than the current setting is ignored.
- Validation warnings are written to the REAPER console.
- `fetch` never raises.
