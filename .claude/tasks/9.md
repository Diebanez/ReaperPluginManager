# Task 9 — Project file scanner

Target: claude

## Goal
Implement the project scanner of feature `plugin-detection`: read every
plugin reference out of a saved `.rpp` project file, wherever it sits, with
instance counts — the input of every project check.

## Acceptance criteria
- `scan_project(text)` treats every line that, trimmed, starts with `<VST `,
  `<AU `, `<CLAP `, `<LV2 ` or `<DX ` as a plugin reference — track chains,
  master, take FX (`<TAKEFX`) and containers (`<CONTAINER`) alike; `<JS`
  lines are excluded.
- The tokenizer splits on spaces and honours tokens quoted with `"`, `'` or
  `` ` ``; token 2 is the display name, token 3 the identifier.
- Returns distinct references by (tag, display name, identifier) with an
  instance count, in order of first appearance.
- The five example lines of SPEC.md §4.1 (VST3i with `(48 out)`, VSTi
  Kontakt, VST ReaComp unquoted identifier, AU, CLAP) tokenize to the
  expected name and identifier.
- A malformed line is skipped, never fatal; an empty project yields no
  references. Pure Lua, no `reaper.*` calls.
